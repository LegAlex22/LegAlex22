<p dir="auto"><strong>Customize Settings</strong>: Adjust the parameters as needed:</p>
<ul dir="auto">
<li><code>game</code>: The arcade game name to generate. For valid names, see table above.</li>
<li><code>username</code>: Your GitHub or GitLab username.</li>
<li><code>platform</code>: Specify <code>'github'</code>, <code>'gitlab'</code> or <code>'scenario'</code>.</li>
<li><code>gameTheme</code>: Choose between <code>'github'</code>, <code>'github-dark'</code>, <code>'gitlab'</code>, or <code>'gitlab-dark'</code>.</li>
<li><code>scenario</code>: Use a predefined contribution scenario instead of fetching platform contributions. Available scenarios: <code>full</code>, <code>empty</code>, <code>random</code>, <code>checkerboard</code>, <code>gradient</code>, <code>streaks</code>. This option is only active when <code>platform</code> is set to <code>'scenario'</code>; with <code>platform: 'github'</code> or <code>platform: 'gitlab'</code>, real platform contributions are fetched and the scenario value is ignored.</li>
<li><code>playerStyle</code> <em>(Pac-Man only)</em>: <code>PlayerStyle.OPPORTUNISTIC</code> (default), <code>PlayerStyle.CONSERVATIVE</code>, or <code>PlayerStyle.AGGRESSIVE</code>.</li>
<li><code>showMonthLabels</code>: <code>true</code> (default) renders the month labels row above the grid; set to <code>false</code> for a cleaner, header-free SVG.</li>
<li><code>svgCallback</code>: Called with the finished SVG string once generation is complete.</li>
<li><code>gameOverCallback</code>: Called when the game finishes.</li>
<li><code>pointsIncreasedCallback</code>: Called each time the score increases.</li>
<li><code>gameStatsCallback</code>: Called at the end with <code>{ totalScore, steps, ghostsEaten }</code>.</li>
<li><code>githubSettings</code>: <code>{ accessToken: 'your_token' }</code> for private contribution data.</li>

<p dir="auto">The application uses your GitHub contribution data to:</p>
<ol dir="auto">
<li>Create a grid where each cell represents a day of contribution</li>
<li>Use the contribution intensity levels provided by the GitHub API:</li>
</ol>
<ul dir="auto">
<li>NONE: Days with no contributions (empty spaces in the game)</li>
<li>FIRST_QUARTILE: Days with few contributions (small points, 1 point in the game)</li>
<li>SECOND_QUARTILE: Days with moderate contributions (medium points, 2 points)</li>
<li>THIRD_QUARTILE: Days with many contributions (large points, 5 points)</li>
<li>FOURTH_QUARTILE: Days with exceptional contributions (power pellets that activate ghost-eating mode)</li>
</ul>
<p dir="auto">These levels are relative to each user's contribution pattern and are automatically calculated by GitHub, so the density of elements in the game will reflect each user's unique profile.</p>
<ol start="3" dir="auto">
<li>Pac-Man navigates the grid using pathfinding algorithms</li>
<li>Ghosts chase Pac-Man with unique behaviors (as in the original game)</li>
<li>All gameplay is recorded and exported as an animated SVG</li>
</ol>
